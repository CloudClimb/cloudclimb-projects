# CloudClimb Projects

CloudClimb is a community focused on giving people hands-on experience working through real-world cloud engineering projects.

The goal is to build projects over time instead of completing random, disconnected labs. Contributors will work through requirements, infrastructure changes, troubleshooting, documentation, GitHub workflows, and team collaboration similar to how an actual cloud engineering team would operate.

## Cloud Platforms

Current project tracks:

- AWS
- Azure

GCP may be added as the community grows.

## How Projects Work

Each project starts from the ground up and is broken into stages or checkpoints.

Each checkpoint builds on the previous one until contributors have a complete working cloud environment.

Projects may include:

- Cloud networking
- Identity and access management
- Infrastructure as Code
- Terraform
- Application deployment
- CI/CD
- Monitoring and logging
- Security
- Troubleshooting
- Documentation
- Git and GitHub workflows

## Contributing

CloudClimb uses branches, pull requests, and code reviews to give contributors experience with a real engineering workflow.

Contributors should not make project changes directly to the `main` branch.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the full contribution process.

## Cloud Accounts

Participants will generally deploy project resources using their own AWS or Azure accounts.

This allows everyone to get hands-on experience while avoiding the cost and complexity of running every participant's infrastructure inside one shared CloudClimb account.

Participants are responsible for monitoring their own cloud usage and removing resources when they are no longer needed.
