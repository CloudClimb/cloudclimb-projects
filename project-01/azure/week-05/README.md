# Core Concepts

Before building anything, understand these three concepts.

## Metrics

Metrics are numerical measurements collected over time.

Examples:

```text
CPU percentage
Memory usage
Disk usage
Network traffic
Database connections
Request count
```

Metrics help answer:

> "How is the system performing?"

---

## Logs

Logs contain detailed events generated by systems and applications.

Examples:

```text
SSH login attempts
Linux system messages
Docker errors
Application errors
Database connection failures
Service failures
```

Logs help answer:

> "What happened?"

---

## Alerts

Alerts watch metrics or logs and notify you when a condition occurs.

Example:

```text
CPU > 80% for 5 minutes
```

or:

```text
VM becomes unavailable
```

or:

```text
Application starts returning errors
```

Alerts help answer:

> "When should somebody investigate?"

# Troubleshooting Exercise

For both tracks, work through this scenario:

> A user reports that Memos is no longer loading.

Do not immediately start changing infrastructure.

Work through the system layer by layer.

Example:

```text
Is the VM / EC2 instance running?
          |
          v
Is the application container running?
          |
          v
Is port 5230 listening?
          |
          v
Are NSG / Security Group rules correct?
          |
          v
Can the application reach PostgreSQL?
          |
          v
Is PostgreSQL healthy?
          |
          v
What do the logs show?
```

Useful Linux commands may include:

```bash
docker ps
```

```bash
docker logs memos
```

```bash
ss -tulpn
```

```bash
df -h
```

```bash
free -m
```

```bash
top
```

For database connectivity:

```bash
nc -vz DATABASE_FQDN 5432
```

or the AWS RDS endpoint equivalent.

# Cost Awareness

Monitoring can generate additional cloud costs.

Pay attention to:

- Log ingestion
- Log retention
- Alerting
- Storage
- Metrics
- VM runtime
- Database runtime

For this lab, keep log collection and retention reasonable.

Delete resources that are no longer needed after completing the project.
