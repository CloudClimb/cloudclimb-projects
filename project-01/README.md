# Project 01

Project 01 is currently being developed by the CloudClimb AWS and Azure teams.

The goal is to create one real-world cloud engineering project that can be implemented across both AWS and Azure using services appropriate to each platform.

## Current Status

The business scenario, technical requirements, project checkpoints, and final architecture are still being discussed and finalized.

This directory will be used by the AWS and Azure teams to collaborate on the project structure before it is released to the rest of the CloudClimb community.

## Project Goals

Project 01 will be designed to:

- Build infrastructure from the ground up
- Give contributors experience working from requirements instead of step-by-step lab instructions
- Use Infrastructure as Code where appropriate
- Include Git and GitHub collaboration
- Include real-world cloud engineering concepts
- Build on previous work instead of using disconnected labs
- Provide equivalent AWS and Azure implementations of the same overall business scenario

## Platforms

### AWS

AWS-specific planning, architecture, infrastructure, and documentation will be located in:

`project-01/aws/`

### Azure

Azure-specific planning, architecture, infrastructure, and documentation will be located in:

`project-01/azure/`
